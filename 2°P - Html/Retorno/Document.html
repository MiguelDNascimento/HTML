Introdução à Responsividade

Responsividade é uma abordagem de desenvolvimento web que permite que o layout se adapte automaticamente ao tamanho da tela, oferecendo uma boa experiência em smartphones, tablets, notebooks e monitores.

Media Queries

Permitem alterar o CSS conforme características do dispositivo, como a largura da tela. É com elas que definimos os breakpoints.

Flexbox

É utilizado para organizar elementos em uma direção, linha ou coluna, facilitando alinhamento e distribuição dos componentes.

CSS Grid

Trabalha com linhas e colunas, sendo indicado para estruturas de layout mais complexas e bidimensionais.
